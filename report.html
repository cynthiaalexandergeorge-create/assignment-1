1. Executive Summary

This project delivers a multi-page personal portfolio, curriculum vitae, and bio-data web platform designed to satisfy academic web development laboratory specifications. The web platform establishes a professional online digital identity for Cynthia Alexander, an engineering student at Jain College, Hubli.

Starting from foundational laboratory reference specifications, the system was re-architected following contemporary UI/UX design standards, semantic HTML5 structure, modern CSS3 layout systems (CSS Grid and Flexbox), vanilla JavaScript for DOM manipulation, and pure SVG vector graphics. The completed codebase is version-controlled with Git, maintained on GitHub, and hosted on the Vercel Edge Network.

4. Key Design & Engineering Techniques

Pure SVG Vector Engineering: Casual emoji characters were systematically eliminated in favor of clean, resolution-independent SVG vector iconography. Stroke-based geometry (viewBox="0 0 24 24", stroke-width="2") ensures sharp rendering across high-DPI retina displays and seamless theme color inheritance via currentColor.
  • CSS Design Tokens: Unified stylesheet utilizing variables for brand colors (--primary: #ff5e62, --accent-lime: #ccff00, --dark-bg: #090a0f) and typography scales.
  • Responsive Viewport Breakpoints: Dynamic media queries at 900px and 650px ensuring accessibility across smartphones, tablets, and desktop workstations.
  • Semantic Markup: Proper use of <header>, <nav>, <main>, <section>, and <footer> for optimal screen reader accessibility and SEO.
