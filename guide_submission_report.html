Abstract

The rapid proliferation of web technologies has made interactive, responsive personal websites a standard requirement for computing professionals to present their academic credentials, research endeavors, and technical portfolios. This laboratory project encompasses the engineering, design enhancement, version-control integration, and cloud deployment of a multi-page personal web application for Cynthia Alexander.

Chapter 4: Design Techniques & SVG Engineering

4.1 Elimination of Casual Emojis in Favor of SVG Vectors

A critical design enhancement introduced during development was the complete elimination of casual platform emojis. Emojis render inconsistently across operating systems and diminish professional credibility.

All icons were re-engineered using Scalable Vector Graphics (SVG) with uniform 24×24 coordinate viewBox geometry, 2px stroke width, rounded line-caps, and dynamic color inheritance via currentColor: 

<!-- Example: Professional SVG Email Icon -->
<svg width="18" height="18" viewBox="0 0 24 24" fill="none" 
     stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <rect width="20" height="16" x="2" y="4" rx="2"/>
  <path d="m22 7-8.97 5.7a1.94 1.94 0 0 1-2.06 0L2 7"/>
</svg>

4.2 CSS Design Tokens & Palette Architecture

To ensure visual cohesion, CSS custom properties were implemented across all components:

  • --primary: #ff5e62 (Coral / Terracotta accent for buttons, active links, and brand icons).
  • --accent-lime: #ccff00 (High-visibility electric lime for badges and rotating highlights).
  • --dark-bg: #090a0f (Obsidian black for ticker banners and footer elements).
  • --text-main: #0f172a & --text-muted: #64748b (High-contrast WCAG 2.1 AA accessible typography).

4.3 Responsive Viewport Strategy

The stylesheet implements progressive enhancement with fluid media queries:

  • Desktop (> 900px): Two-column CSS Grid layouts with generous spacing and visible horizontal navigation.
  • Tablet (650px – 900px): Grid columns collapse to single-column centered layouts while maintaining card containment.
  • Mobile (< 650px): Navigation transitions to a clean slide-down menu toggled via JavaScript, tables receive horizontal scrolling wrappers, and typography scales appropriately.
